# Deploy (Mini PC / CasaOS)

This folder is a deployment bundle for replacing an existing Stremio nCore addon instance on a mini PC.

## 0) Backup (recommended)

On the mini PC, back up your persistent data folder (contains DB, torrents, downloads):

- `/DATA/AppData/stremio-ncore-addon/`

## 1) Load the Docker image

If you have `stremio-ncore-addon-image.tar` in this folder:

```sh
docker load -i stremio-ncore-addon-image.tar
```

It will load as `stremio-ncore-addon:custom`.

> [!IMPORTANT]
> If you get `exec /usr/local/bin/docker-entrypoint.sh: exec format error`, the image architecture does not match your mini PC.
> Example: the image was built as `linux/arm64` but the mini PC is `x86_64`.
>
> Fix: build the image on the mini PC (recommended), or build an `amd64` image using `docker buildx`.

## 2) Stop/remove the old container

If you deployed via CasaOS App Store / previous compose, stop it first.

Then (optional) remove the old container:

```sh
docker ps -a --format 'table {{.Names}}\t{{.Image}}'
# docker stop <name>
# docker rm <name>
```

## 3) Start the new version

### Option A: docker-compose

1. Copy `.env.template` to `.env` and fill it:

```sh
cp .env.template .env
nano .env
```

2. Start:

```sh
docker compose up -d
```

### If you need to build on the mini PC (recommended)

If you have `stremio-ncore-addon-src.tar.gz` available:

```sh
mkdir -p ~/stremio-ncore-addon-build
tar -xzf stremio-ncore-addon-src.tar.gz -C ~/stremio-ncore-addon-build
cd ~/stremio-ncore-addon-build

# After extraction you should see Dockerfile here
ls -la Dockerfile

docker build -t stremio-ncore-addon:custom .
```

### Option B: CasaOS import

In CasaOS, create a **Custom App** and import `casaos-app.yml`.

## 4) Ports / volume

- HTTP: `3001/tcp` (host) -> `3000/tcp` (container)
- HTTPS (local-only mode): `3443/tcp`
- Torrent seeding: `42069/tcp` and `42069/udp`
- Volume mount: `/DATA/AppData/stremio-ncore-addon:/addon`

## 5) Finish setup

Open:

- `http://<mini-pc-ip>:3001` for the web UI

Then complete the wizard (or reuse existing config if the DB folder was reused).

## 6) Add to Stremio

After setup, use your addon URL + `/manifest.json`.

Examples:

- `http://<mini-pc-ip>:3001/manifest.json`
- Local-only HTTPS URL is generated by the UI (uses `local-ip.medicmobile.org`)
